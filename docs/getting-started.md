# Getting Started

Part of the [Vicena Research Twins](https://vicena.ai) collection.

Install with `python -m pip install -e .`. Validate the bundled CSV, run `python examples/quickstart.py`, then execute `hvac-twin run datasets/example/building_timeseries.csv --output outputs/reference_run`. Inspect `summary.json` before plots. For measured data, read the data contract, preserve raw files, declare timezone and interval semantics, choose a chronological split, and document exclusions.
